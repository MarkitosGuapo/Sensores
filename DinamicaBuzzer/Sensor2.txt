En este proyecto desarrollamos un programa cuyo objetivo fue simular un sistema de seguridad utilizando un sensor infrarrojo con control remoto, un buzzer y una pantalla LCD1602 con interfaz I2C. El funcionamiento consistía en que, al iniciar el sistema, la pantalla mostrara un mensaje de espera indicando que estaba listo para recibir una entrada. Posteriormente, se ingresaba una contraseña previamente establecida en el código (1, 2, 3).

Cuando se ingresaba un valor incorrecto, el buzzer emitía un sonido fuerte de alerta y la pantalla desplegaba un mensaje indicando el error. En cambio, si la contraseña era correcta, el sistema mostraba un mensaje de acceso permitido o bienvenida en la pantalla. Este mecanismo permitió simular un acceso seguro controlado mediante un sensor IR.
